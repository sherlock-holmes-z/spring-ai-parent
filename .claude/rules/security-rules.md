## Security Rules（Claude 必须严格遵守）

### 绝对禁止
- 禁止在代码中硬编码 API Key / 密码 / Token / 证书
- 禁止提交 .env 文件 / application-prod.yml / 任何含真实密钥的配置
- 禁止生成含真实生产环境 IP / 域名的代码
- 禁止在日志中打印用户密码、身份证、手机号等敏感字段
- 禁止在 Git 历史中出现 secret / password / accessKey 明文

### 敏感数据处理
- 所有密钥通过环境变量或 Nacos 配置中心注入
- 日志脱敏：手机号保留前 3 后 4，身份证保留前 6 后 4
- 数据库密码字段存储必须加密（AES-256）

### 依赖安全
- 新增依赖前确认无已知 CVE 漏洞
- 禁止引入 GPL 协议依赖到商业模块
