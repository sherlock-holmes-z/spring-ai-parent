# Claude Code Settings 配置说明

本文档详细解释 `.claude/settings.json` 中的各项配置。

---

## 配置概览

当前配置采用**简化模式**，包含核心权限控制、基础设置和自动化钩子。

---

## 1. 权限控制 (permissions)

### allow（白名单）
以下操作类型**无需确认**即可执行。

| 配置项 | 说明 |
|--------|------|
| `Read` | 读取所有文件 |
| `Write` | 写入所有文件 |
| `Bash(npm *)` | 所有 npm 命令 |
| `Bash(git *)` | 所有 git 命令 |
| `Bash(node *)` | 运行 node 脚本 |

**注意：** 当前配置允许写入所有文件，请确保在信任的项目中使用。

---

### deny（黑名单）
**绝对禁止**的操作（优先级高于 allow）。

| 配置项 | 说明 |
|--------|------|
| `Bash(rm -rf *)` | 禁止执行危险删除操作 |

此规则防止误删重要文件和目录。

---

## 2. 模型选择 (model)

控制 Claude 使用的模型。

**当前配置：** `"sonnet"`

**可选值：**
- `"sonnet"` - 平衡速度与质量（默认，推荐）
- `"opus"` - 最强能力，适合复杂推理（较贵）
- `"haiku"` - 最快最便宜，适合简单任务

---

## 3. 上下文压缩阈值 (autoCompactThreshold)

当对话历史超过该百分比时，自动压缩历史以避免超限。

**当前配置：** `80`（即 80%）

**说明：**
- 当对话达到上下文限制的 80% 时，自动压缩早期内容
- 有助于保持对话连续性，同时避免超出 token 限制

---

## 4. 钩子 (hooks)

自动化生命周期回调，在特定时机执行自定义命令。

### PostToolUse（执行后触发）
在工具执行**之后**触发。

**当前配置：**
```json
{
  "matcher": "Write(.claude/settings.json)",
  "hooks": [
    {
      "type": "command",
      "command": "echo 'settings.json 已修改，请手动更新 settings.md 以保持一致'"
    }
  ]
}
```

**功能说明：**
- 监听 `.claude/settings.json` 文件的写入操作
- 当文件被修改时，在控制台输出提示信息
- 提醒开发者同步更新 `settings.md` 文档

---

## 默认交互模式

当前配置未设置 `defaultMode`，将使用系统默认值（通常为 `normal`，即每次操作需确认）。

**可选模式：**
- `"normal"` - 每次操作都需确认
- `"acceptEdits"` - 自动接受文件编辑，其他需确认
- `"plan"` - 只规划不执行
- `"bypassPermissions"` - 全自动模式

---

## 最佳实践

1. **日常开发：** 当前配置已允许写入操作，适合日常开发
2. **安全保护：** `deny` 规则防止危险删除操作
3. **成本控制：** 使用 `sonnet` 模型平衡性能和成本
4. **团队协作：** 可根据团队需求调整权限规则
5. **文档同步：** 修改配置后记得更新本文档

---

## 注意事项

- JSON 格式**不支持注释**，如需说明请参考本文档
- 当前配置允许写入所有文件，请在信任的项目中使用
- 如需更精细的权限控制，可添加更具体的 allow/deny 规则
- 钩子配置可以帮助实现配置文件的自动化维护
